# 게임 카드 레이아웃 동일 적용 규칙

## 규칙

아래 "동일 그룹" 목록에 속한 화면은 전부 같은 "게임 카드"를 보여준다. **하나의 카드 레이아웃(구조, 클래스, 스타일)을 수정하면, 사용자가 그 자리에서 명시적으로 "이건 다르게 해줘"라고 지정하지 않는 한 — 즉 사용자가 별도로 말하기 전까지는 항상 — 목록의 나머지 전부에도 동일하게 적용한다.**

- 사용자에게 "다른 곳에도 적용할까요?"라고 되묻지 않는다 — 무조건 전부 동일하게 반영한다.
- 새로 게임 카드를 보여주는 화면을 추가하는 경우, 이 문서의 목록에도 추가한다.
- 기준(원본)은 `/betazone` (`BetazonePage.tsx`)의 카드다. 다른 위치를 수정할 때는 이 카드의 구조를 기준으로 맞춘다.
- 두 파일의 `GameCard`/`LiveGameCard` 함수는 함수명만 다르고 나머지는 **완전히 동일한 코드**여야 한다 (2026-08-26 기준 diff로 확인 완료). 한쪽만 고치고 다른 쪽을 잊는 실수를 막기 위해, 수정 후에는 두 함수 본문이 여전히 동일한지 diff로 확인하는 습관을 들인다.

### 현재 카드 구성 (2026-09-02 갱신)

여러 차례 요청으로 계속 단순화되어 왔다 — 새로 뭔가 추가/복원할 때는 최신 상태인 이 목록을 기준으로 판단한다.

- 썸네일 이미지 (`aspect-[5/5]`(정사각형), `object-cover`, 호버 시 확대 — 2026-09-02 "5:5로 넣어봐" 요청으로 기존 `aspect-[39/20]`에서 변경)
- 제목 (`truncate`, 1줄, `text-[18.2px]` — 2026-09-02 "30% 키워" 요청으로 기존 `text-sm`(14px)에서 확대)
- 설명 (줄 수 제한 없이 전체 텍스트 표시 — 2026-09-02, "한 줄로 줄여" 요청 후 바로 "그냥 다 나오게 해" 요청으로 되돌림. `line-clamp`/`min-h` 전부 제거. 제목과의 간격 `mt-[2.4px]`(기존 `mt-0.5`에서 20% 확대), 왼쪽으로 살짝 들여쓰기 `pl-1`)
- 카드 높이 통일: 그리드(`grid`)의 기본 `align-items: stretch`를 활용 — 카드 루트 `div`에 `h-full`, 내부 테두리 박스에 `h-full flex flex-col`, 텍스트 영역에 `flex-1`을 줘서 **한 행(row) 안에서 설명이 가장 긴 카드 높이에 나머지가 자동으로 맞춰짐** (하드코딩된 고정 높이가 아니라 그때그때 가장 큰 카드 기준, 2026-09-02)
- 위 세 가지가 **하나의 테두리 안에** 통합된 단일 카드 (`border-2 border-gray-300 dark:border-gray-600`, `rounded-2xl`) — 이미지와 텍스트가 분리된 두 블록이 아니라 한 장의 카드
- 평점: 공용 컴포넌트 `StarRating`(`apps/web/src/components/StarRating.tsx`, `size={3.5}`) + 숫자(`(game.rating || 0).toFixed(1)`, `text-yellow-400 font-bold text-xs`) — 2026-09-02 "평점이랑 장르 다시 넣어" 요청으로 복원, 이후 "평점 디자인이랑 칼라 통일" 요청으로 사이드바 별점과 같은 공용 컴포넌트로 교체 (자세한 내용은 `docs/rating-consistency-rule.md` 참고)
- 장르: 평점 아래, 배지(Badge)가 아니라 순수 텍스트로 `game.genre` 표시 (`text-xs text-accent`, 없으면 미표시) — 2026-09-02 "배찌로 하지말고 텍스트로" 요청으로 배지 대신 텍스트로 변경
- 평점/장르 위치 고정: 제목+설명을 담는 블록과 평점/장르 블록을 분리하고, 텍스트 영역 전체(`p-2 flex-1 flex flex-col`)에서 평점/장르 블록에 `mt-auto`를 줘서 **설명 줄 수가 카드마다 달라도 평점/장르는 항상 카드 하단 동일한 위치**에 정렬됨 (2026-09-02, "설명 줄이 달라도 평점이랑 장르는 동일한 위치에" 요청)
- 평점/장르 블록도 설명과 동일하게 `pl-1`로 오른쪽 들여쓰기 (2026-09-02, "평점이랑 장르도 설명 행 위치만큼 오른쪽으로 이동" 요청)
- 카드 폭/간격: 그리드 컨테이너의 가로 간격 `gap-x-6`(24px) → `gap-x-[122px]` — 카드 개수(4열)와 컨테이너 폭은 그대로 두고 간격만 넓혀서 결과적으로 카드 폭이 정확히 25% 줄어듦(294px → 220.5px, 2026-09-02 xl 4열 기준 실측). 세로 간격(`gap-y-[28px]`)은 변경 없음

**제거된 것들 (요청에 따라 순차적으로 삭제됨, 함부로 복원하지 않는다)**: 찜하기(하트) 버튼, 플레이 수, GRAC 등급 배지, 가격 표시, accent 컬러 테두리/배경. "컬러는 따로 넣지 말고" 요청이 있었으므로 카드 틀 자체는 브랜드 컬러 강조 없이 중립(회색) 톤 유지 (단, 장르 배지 색상은 예외로 accent 사용). 별점·장르는 2026-09-02 재요청으로 복원되었으므로 이 제거 목록에서 제외.

## 동일 그룹 (게임 카드를 보여주는 위치)

| 위치 | 파일 |
|------|------|
| 베타존 (`/betazone`) — 기준 | `apps/web/src/components/pages/BetazonePage.tsx` |
| 라이브게임 (`/live_games`) | `apps/web/src/components/pages/LiveGamesPage.tsx` |

공통 컴포넌트로 분리되어 있지 않고 각 파일에 인라인으로 중복 구현되어 있으므로(`GameCard`/`LiveGameCard`), 수정 시 두 파일을 모두 열어 직접 반영해야 한다.

## 발견/변경 이력

**2026-08-26**:
1. 두 화면의 카드가 거의 동일했지만 `LiveGamesPage.tsx`에만 GRAC 등급 배지(`GracRatingBadge`) 표시 블록이 빠져있었다 — 사용자가 "베타존, 라이브게임 전부 카드 레이아웃 동일하게" 요청해서 발견, `BetazonePage.tsx` 기준으로 배지 블록을 추가해 통일함.
2. "하트 눌러도 아무 기능 없다"는 지적 후 찜하기(하트) 버튼 완전 제거.
3. "썸네일/이름/설명/평점 외 다 삭제" 요청으로 플레이 수·GRAC 배지·장르 배지·가격 제거.
4. "평점도 삭제" 요청으로 별점도 제거 — 이제 썸네일+제목+설명만 남음.
5. "컬러는 따로 넣지 말고 트렌디하게" 요청으로 accent 컬러 테두리 제거, `Card`/`CardContent` 공용 컴포넌트 사용도 그만두고 커스텀 마크업으로 전환(`rounded-2xl`, `aspect-[4/3]`).
6. "테두리가 없어서 게임 간 구분이 안 된다" — 처음엔 `ring-black/10` 등 옅은 색으로 시도했으나 흰 배경/어두운 썸네일 양쪽에 너무 안 보여서 실패. `ring` 유틸리티 자체도 잘 안 먹혀서, 확실한 `border-2 border-gray-300 dark:border-gray-600`로 교체해 해결.
7. "제목·설명까지 썸네일이랑 같은 한 카드가 됐으면" 요청으로 이미지+텍스트를 하나의 테두리 안에 통합(이전엔 테두리가 이미지에만 있고 텍스트는 바깥에 있었음).
8. "글자 수 상관없이 카드 크기 고정" 요청으로 설명에 `min-h-[2.5rem]` 추가 — 설명이 1줄이든 2줄이든 카드 높이가 항상 동일하게 유지됨.
9. 사용자가 "베타존/라이브게임은 내가 뭐라고 말하기 전까지는 항상 레이아웃 동일하게 수정하고 이 문서에도 반영해놔"라고 명시적으로 재확인 — 이 규칙 문서 자체가 그 요청에 따른 것.
10. 2026-09-02, "짧은 설명은 한 줄로 하고 넘으면 ...으로 줄여" 요청으로 `line-clamp-2` → `line-clamp-1`로 축소했다가, 곧바로 "그냥 설명 다 나오게 해" 요청으로 `line-clamp`/`min-h` 전부 제거하고 전체 텍스트 노출로 되돌림 (두 파일 동일 반영).
11. 2026-09-02, "이전같이 평점이랑 장르 다시 넣어", "설명 아래에" 요청으로 별점(★ 5개 + 숫자)과 장르 배지를 설명 아래에 복원 (찜하기/플레이 수/GRAC 배지/가격은 복원 대상 아님, 두 파일 동일 반영).
12. 2026-09-02, "설명 줄이 달라도 평점이랑 장르는 동일한 위치에 나오게 하고 장르는 배찌로 하지말고 텍스트로 넣어" 요청으로 (a) 장르를 `Badge` 컴포넌트에서 순수 텍스트(`text-xs text-accent`)로 변경, (b) 텍스트 영역을 `flex flex-col`로 바꾸고 평점/장르 블록에 `mt-auto`를 줘서 설명 줄 수와 무관하게 카드 하단에 항상 고정 (두 파일 동일 반영).
13. 2026-09-02, "카드 넓이 25% 정도 줄이고 카드 간 간격을 넓혀서 배치를 지금처럼 해" 요청으로 그리드 컨테이너의 `gap-x-6` → `gap-x-[122px]`로 변경 — 카드 자체 크기값을 직접 건드리지 않고 그리드 `fr` 트랙 특성상 간격을 넓히면 카드 폭이 자동으로 줄어드는 것을 이용, xl 4열 기준 실측으로 정확히 25% 축소 확인 (두 파일 동일 반영).
14. 2026-09-02, "카드 썸네일을 5:5로 넣어봐" 요청으로 썸네일 컨테이너 `aspect-[39/20]` → `aspect-[5/5]`(정사각형)로 변경 (두 파일 동일 반영).
15. 2026-09-02, "평점이랑 장르도 설명 행 위치만큼 오른쪽으로 이동" 요청으로 평점/장르 블록에 설명과 동일한 `pl-1` 추가 (두 파일 동일 반영).
16. 2026-09-02, "평점 디자인이랑 칼라, 밖에 카드에 평점이랑 통일시켜" 요청으로 카드의 별점을 `lucide-react`의 `Star` 직접 렌더링에서 공용 `StarRating` 컴포넌트로 교체, 숫자 색상도 `text-yellow-400 font-bold`로 통일. 이 요청을 계기로 "평점 어디 들어가든 같은 디자인" 규칙을 `docs/rating-consistency-rule.md`로 신설함 — 앞으로 별점 관련 변경은 그 문서도 함께 확인/갱신할 것.

## 참고: 카드 레이아웃 외 필터 기능도 동일 그룹 적용 대상

- 이 문서는 "카드 레이아웃"에 초점을 맞추고 있지만, 라이브존/베타존은 **필터 바(장르 태그, "내 게임" 태그 등)도 항상 동일하게 유지**한다. 2026-08-27, 라이브존에만 "내 게임" 필터 태그를 추가했다가 "둘 다 동시에 하라고 했잖아" 지적을 받고 베타존에도 동일 반영함 — 관련 메모리 [[feedback_betazone_livegame_card_sync]].
- "내 게임" 태그의 판정 기준/동작 규칙은 `docs/platform-rules.md` 1.8절 참고.

## 이 그룹에서 제외되는 것 (의도적 제외)

- `apps/web/src/components/pages/GameListPage.tsx` — 게임 카드 구조 자체는 동일하지만 앱 라우터에 연결되어 있지 않은(사용되지 않는) 페이지라 그룹 대상에서 제외. 실제로 라우팅에 연결되면 그룹에 편입하고 이 문서도 업데이트한다.
- 메인 화면(`MainPage.tsx`)의 게임 카드 — 홈 화면 전용으로 의도적으로 더 단순화된 다른 스타일이며, 이 그룹의 "탐색/목록" 카드와는 성격이 다르다.

## 예시

"베타존 카드에 좋아요 수 표시 추가해" 같은 요청을 받으면, 베타존뿐 아니라 위 "동일 그룹" 표에 있는 `LiveGamesPage.tsx`의 카드에도 같은 변경을 자동으로 함께 반영한다.
