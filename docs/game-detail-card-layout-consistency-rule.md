# 게임 상세 페이지 카드 폭·위치·간격 통일 규칙 (베타존)

`PlayerGameDetailPage.tsx`의 베타존(`serviceType === 'beta'`) "게임 소개" 탭에서, 아래 카드들은 하나의 그룹으로 취급되어 폭·좌우 위치·카드 사이 간격이 전부 동일 비율로 맞춰져 있다 (2026-09-17).

## 확정 스펙 (1440px 기준 실측)

- 좌측 그룹 — `lg:basis-[53.7%]` (실측 폭 약 661.5px): "개발사 정보" 카드, "게임 설명" 카드
- 우측 그룹 — `lg:basis-[22.32%]` (실측 폭 약 275px): "평점" 카드(별점+리뷰수), "다른 베타 신청하기" 카드, "별점 분포" 카드
- 좌우 그룹 사이 간격 — 스페이서 `lg:basis-[0.34%]` + 좌우 `gap-3`(12px)×2 = 약 28px(1440px 기준)
- 구현 구조: `lg:col-span-2 flex flex-col lg:flex-row lg:justify-center gap-3 items-start` 래퍼 안에 [좌측 그룹, 스페이서, 우측 그룹] 3파츠 — 이 구조가 "게임 소개" 탭 **상단 블록**(개발사 정보/게임 설명 ↔ 평점/다른 베타 신청하기)과 **리뷰 영역 하단 블록**(리뷰 목록 ↔ 별점 분포)에 각각 독립적으로 적용돼 있고, 두 블록의 basis 값이 서로 동일해야 시각적으로 위아래 좌우 끝이 맞음
- 그룹 전체는 `lg:justify-center`로 화면(콘텐츠 영역) 정중앙에 위치 — 좌/우 basis 합이 100%가 아니라 남는 폭이 생기는데, 이 여백을 오른쪽으로 몰지 않고 좌우 균등하게 분배함(2026-09-17)
- 라이브존은 이 규칙 대상이 아님 — 라이브존은 그대로 공용 `grid-cols-[11fr_3.2fr]` 그리드를 사용하며 폭이 다름(사이드바 실측 약 279px)

## 적용 대상 (동일 그룹)

우측 그룹 폭(`basis-%`)이나 스페이서 폭을 수정하면, 사용자가 명시적으로 다르게 하라고 하지 않는 한 **묻지 않고 상단 블록·하단 블록 양쪽의 해당 값 전부에 동일하게 적용**한다.

- 상단 블록: 개발사 정보 카드 wrapper(`basis-[53.7%]`), 게임 설명 카드, 스페이서(`basis-[0.34%]`), 평점 카드+다른 베타 신청하기 카드를 담는 우측 컨테이너(`basis-[22.32%]`)
- 하단 블록: 리뷰 목록을 담는 좌측 컨테이너(`basis-[53.7%]`), 스페이서(`basis-[0.34%]`), 별점 분포 카드(`basis-[22.32%]`)

새로 이 페이지의 베타존 레이아웃에 카드를 추가하면 이 좌/우 basis 값을 그대로 따르고, 이 문서의 목록도 함께 업데이트한다.

(참고: 카드 "제목"의 폰트 크기/굵기 통일은 별도 문서 `docs/game-detail-card-title-consistency-rule.md`를 따른다 — 이 문서는 폭/위치/간격만 다룬다.)
