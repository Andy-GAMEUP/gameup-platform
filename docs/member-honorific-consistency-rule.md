# "회원" 대신 "회원님" 사용 규칙

## 규칙

관리자 화면 등에서 **회원 개인을 직접 지칭하거나, 회원에게 전달/안내하는 문구**를 쓸 때는 무조건 "회원" 대신 "회원님"을 쓴다.

- 예: "회원에게 직접 전달하세요" → "회원님에게 직접 전달하세요"
- 새로 이런 종류의 문구(안내/확인 팝업 메시지, 알림 문구 등)를 추가할 때도 항상 "회원님"으로 쓴다
- 사용자가 특정 화면을 지목해 바꿔달라고 할 때마다 그 화면부터 순차 적용하며, 발견하는 대로 이 문서에도 반영한다

## 예외 (구조적 명칭은 대상 아님)

아래처럼 "회원"이 개인을 직접 지칭/호칭하는 게 아니라 **화면 제목, 목록/기능의 구조적 명칭**으로 쓰이는 경우는 이 규칙 대상이 아니다 — 굳이 "회원님 관리", "회원님 목록"처럼 바꾸지 않는다.

- 페이지/섹션 제목: "게임회원 상세정보", "기업회원 상세정보", "회원 관리", "회원 목록"
- 상태/카운트 메시지: "회원이 없습니다", "삭제된 회원이 없습니다", "회원 정보를 불러올 수 없습니다"
- 승인/처리 대상을 가리키는 질문형 확인 문구: "이 기업회원을 승인하시겠습니까?" (특정 개인에게 직접 말을 거는 톤이 아니라 대상 객체를 지칭하는 톤)
