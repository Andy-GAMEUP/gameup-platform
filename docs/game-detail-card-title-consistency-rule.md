# 게임 상세 페이지 카드 제목 통일 규칙

`PlayerGameDetailPage.tsx` 안에서 카드(`bg-bg-secondary border border-line rounded-xl`)의 "제목"으로 쓰이는 텍스트는 전부 동일한 폰트 크기·굵기로 맞춘다 (2026-09-17, "이용 등급" 카드 제목을 기준으로 통일).

## 확정 스펙

- `<p className="text-text-primary font-semibold" style={{ fontSize: '18px' }}>제목</p>`
- 색상은 `text-text-primary` 고정, 아이콘 없음
- 제목 앞뒤 여백(`mb-3`/`mb-4` 등)은 카드마다 기존 레이아웃에 맞게 유지 — 통일 대상은 폰트 크기/굵기뿐, 여백까지 강제하지 않는다

## 적용 대상 (동일 그룹)

- 게임 소개 탭 — "게임 설명" 카드
- 개발사 Q&A 탭 — "개발사 Q&A" 카드
- 사이드바 — "이용 등급" 카드 (기준)
- 사이드바 — "개발사 다른 게임 즐기기" 카드 (2026-09-17 신설 — 개발사의 다른 게임을 아이콘·제목·장르로 위→아래 나열, 최대 5개 높이(`max-h-[300px]`)만 보이고 그 이상은 스크롤, 클릭 시 해당 게임 소개 페이지로 이동) — **베타존은 같은 카드가 "다른 베타 신청하기"로 라벨/데이터만 바뀜(아직 시작 안 한 다른 베타 게임을 시작일 임박 순으로 나열), 제목 스펙은 동일(2026-09-17)**
- 사이드바 — "개발사 만나기" 카드
- 리뷰 섹션 — "별점 분포" 카드

하나를 수정하면, 사용자가 명시적으로 다르게 하라고 하지 않는 한 **묻지 않고 위 목록 전부에 동일하게 적용**한다. 새로 이 페이지에 카드(및 카드 제목)를 추가하면 이 스펙(`font-semibold`, `18px`)을 그대로 따르고, 이 문서의 목록도 함께 업데이트한다.

(참고: 히어로 영역의 게임 타이틀(`<h1>`), 탭 바 라벨, 리뷰 개별 항목 안의 사용자 이름 등은 "카드 제목"이 아니므로 이 규칙 대상이 아니다. 베타존 왼쪽 개발사 카드 우측 상단의 작은 "Q&A" 버튼(2026-09-17 신설, `text-xs`)도 카드 "제목"이 아니라 보조 이동 버튼이라 이 규칙 대상이 아님 — 잠깐 사이드바에 18px 전체 카드로 있었다가 이 작은 코너 버튼으로 교체됨.)
