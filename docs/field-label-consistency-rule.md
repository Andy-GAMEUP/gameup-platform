# 입력 필드 라벨 동일 적용 규칙

## 규칙

같은 화면(폼) 안에 있는 입력 필드 라벨(`<label>`)들은 폰트 크기·굵기·색상·여백 등 스타일이 전부 동일해야 한다.

- 라벨 스타일 하나를 수정하면, 사용자가 그 자리에서 "이건 이쪽만 다르게 해줘"라고 명시적으로 지정하지 않는 한 — 즉 사용자가 별도로 말하기 전까지는 항상 — 같은 화면의 나머지 라벨 전부에도 동일하게 적용한다.
- 사용자에게 "다른 필드에도 적용할까요?"라고 되묻지 않는다 — 무조건 전부 동일하게 반영한다.
- 새로 입력 필드를 추가하는 경우, 이 문서에 기록된 현재 스타일을 그대로 따른다.

## 현재 스타일 (가입 화면 `RegisterPage.tsx` 기준, 2026-09-04)

```
className="block text-[15.4px] font-medium text-text-secondary mb-2"
```

- 태그: `<label>`(입력칸에 연결된 라벨) 또는 `<p>`(버튼 그룹처럼 `<label>`이 어색한 경우, 예: "기업 유형")
- 폰트: `text-[15.4px]`(기존 `text-sm`=14px에서 10% 확대, 2026-09-04)
- 굵기: `font-medium`
- 색상: `text-text-secondary`
- 아래 여백: `mb-2`

적용 대상(가입 화면): 이메일, 사용자명, 비밀번호, 비밀번호 확인, 기업 유형, 사업자 등록번호, 회사명, 회사 웹사이트, 대표 연락처, 기업 형태.

## 예외

- "회원 유형"(Step 1) 라벨은 여백만 `mb-3`로 달라서(2026-09-04 기준 미수정 상태) — 개별 입력칸 라벨이 아니라 카드 선택 그룹의 섹션 제목이라 이 규칙 대상에서 제외. 사용자가 통일해달라고 하면 그때 맞춘다.
