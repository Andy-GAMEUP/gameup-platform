# 프로젝트 카드 레이아웃 동일 적용 규칙

## 규칙

아래 "동일 그룹" 목록에 속한 위치는 전부 같은 "프로젝트 카드"(로고+제목/회사명+상태 배지, 금액/마감일/지원자 한 줄, 카테고리+스킬 태그)를 보여준다. **하나의 카드 레이아웃(구조, 클래스, 스타일)을 수정하면, 사용자가 명시적으로 "이건 다르게 해줘"라고 지정하지 않는 한 목록의 나머지 전부에도 동일하게 적용한다.**

- 사용자에게 "다른 곳에도 적용할까요?"라고 되묻지 않는다 — 무조건 전부 동일하게 반영한다.
- 새로 프로젝트 카드를 보여주는 화면을 추가하는 경우, 이 문서의 목록에도 추가한다.
- 기준(원본)은 `/partner/projects` (`PartnerMatchingProjectsPage.tsx`)의 카드다. 다른 위치를 수정할 때는 이 카드의 구조를 기준으로 맞춘다.

## 동일 그룹 (프로젝트 카드를 보여주는 위치)

| 위치 | 파일 |
|------|------|
| 프로젝트 매칭 목록 (`/partner/projects`) — 기준 | `apps/web/src/components/pages/PartnerMatchingProjectsPage.tsx` |
| 파트너 채널 등록 프로젝트 (`/partner/[id]/posts`) | `apps/web/src/components/pages/partner-profile/PostsSection.tsx` |

공통 컴포넌트로 분리되어 있지 않고 각 파일에 인라인으로 중복 구현되어 있으므로, 수정 시 두 파일을 모두 열어 직접 반영해야 한다.

## 왜

두 위치가 같은 "프로젝트"를 서로 다른 화면에서 카드로 보여주는데, 아바타 크기, 제목 줄바꿈 방식, 상태 배지 모양, 지원자 수 표시 위치, CTA 버튼 유무 등이 제각각이면 사용자가 같은 서비스라고 느끼기 어렵다 (2026-07-30, `/partner/projects`와 `/partner/[id]/posts` 카드가 서로 다르게 구현되어 있던 것을 발견해 통일함).

## 예시

"프로젝트 매칭 목록 카드에 배지 옆에 아이콘 추가해" 같은 요청을 받으면, 그 화면뿐 아니라 위 "동일 그룹" 표에 있는 `PostsSection.tsx`의 카드에도 같은 변경을 자동으로 함께 반영한다.
